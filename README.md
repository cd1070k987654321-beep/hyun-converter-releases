# HYUN Converter

영상, 오디오, 이미지 파일을 간단하게 변환할 수 있는 HYUN IT LABS의 Windows 데스크톱 유틸리티입니다.

## 다운로드

최신 설치파일은 **Releases**에서 받을 수 있습니다.

➡️ **[최신 버전 다운로드](https://github.com/cd1070k987654321-beep/hyun-converter-releases/releases/latest)**

## 주요 기능

- 영상 / 오디오 / 이미지 변환
- 드래그 앤 드롭
- 변환 진행률 및 예상 남은 시간 표시
- 영상 화질 / 해상도 / 코덱 설정
- 변환 완료 후 파일 및 폴더 바로 열기
- FFmpeg / ffprobe 내장

## 지원 입력 형식

- 영상: MP4, MOV, MKV, AVI, WEBM, M4V
- 오디오: MP3, WAV, M4A, FLAC, AAC, OGG
- 이미지: JPG, JPEG, PNG, WEBP, HEIC, HEIF

## 지원 출력 형식

- 영상: MP4, MOV, MKV, WEBM
- 오디오: MP3, WAV, M4A, FLAC, AAC
- 이미지: JPG, PNG, WEBP

## 설치 안내

현재 공개된 버전은 Windows x64 테스트 배포판이며 코드 서명이 적용되지 않았습니다.
Windows SmartScreen 경고가 표시될 경우 출처를 확인한 뒤 **추가 정보 → 실행**으로 설치할 수 있습니다.

파일 변환은 사용자의 PC에서 처리되며 FFmpeg / ffprobe가 설치파일에 포함되어 별도 설치가 필요하지 않습니다.
