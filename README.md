# HYUN Converter

HYUN IT LABS의 Windows용 로컬 파일 변환 도구입니다.

## 다운로드

오른쪽 **Releases**에서 최신 버전의 `HYUN-Converter-Setup.exe`를 내려받아 설치하세요.

## 지원 형식

- 영상: MP4, MOV, MKV, AVI, WEBM, M4V
- 오디오: MP3, WAV, M4A, FLAC, AAC, OGG
- 이미지: JPG, JPEG, PNG, WEBP, HEIC, HEIF

## 설치 안내

현재 Windows 코드 서명이 적용되지 않은 테스트 배포판입니다. Windows SmartScreen 경고가 표시될 수 있습니다.
출처를 확인한 뒤 **추가 정보 → 실행**을 선택하면 설치할 수 있습니다.

변환은 로컬 PC에서 처리되며, FFmpeg/ffprobe가 설치파일에 포함되어 별도 설치가 필요하지 않습니다.
